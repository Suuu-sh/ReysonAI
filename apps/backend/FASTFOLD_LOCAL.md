# FastFold v1 — local experimental implementation

The user approved publishing an **experimental beta** on Workers Free with SQLite DO compute, without a paid upgrade. Reviewed local production configuration is now `FASTFOLD_ENABLED=true`; this is not a claim that migration/deployment/live play has happened. The release owner performs additive schema/API readiness/client delivery in order. Real signed-in production play and production CPU observations must be checked after deployment.

- For local development apply migration `0010_fastfold.sql` only to disposable/local storage; approved production delivery executes that exact additive file before the API; existing account/preflop/postflop migrations and published dataset snapshots are also required.
- `npm run test:fastfold` exercises actual Worker routes with HttpOnly local session cookies and in-memory SQLite. It never contacts Google or remote Cloudflare.
- The browser uses the existing account login flow. There is no anonymous rated mode, authentication bypass, or client-authoritative result/seed path.
- `GET /v1/fastfold/status` fails closed when the feature/auth gate, schema/triggers, or required 38 base/profile manifests, contiguous parts, byte lengths or hash formats are missing. Start also verifies content SHA256, unique 169-hand rows and numerical frequencies before dealing. `profile`, `leaderboard` require the existing authenticated browser session; mutation origins and JSON bodies are restricted.
- `POST start {consent:true}` starts or resumes one continuous session. `POST pause {sessionId,version}` pauses without abandoning the hand. `POST action {sessionId,version,actionId,action}` uses a UUID idempotency key and a server-offered legal action. Fold settles the player's actual investment and immediately deals another hand. No daily or total hand cap exists. Rate limiting bounds bursts, not play volume.
- Crypto-shuffled cards and indexed crypto action draws remain in private server state. Public snapshots show only the hero's cards and the board already revealed. At showdown only non-folded opponents reveal cards. No secret seed, draws, private policy, or future board enters a DTO.
- A single compare-and-swap statement plus SQLite triggers commits new hand state, action receipt, unique result(s), and aggregates atomically. Blind walks between decisions are separate counted results. Legacy `ranked_*` records and 20-question mode remain unchanged, never imported into this season.
- Immutable preflop dataset part snapshots survive republishing; the next hand switches to current versions. Flop/later candidates (including missing-data nulls) are pinned privately when first reached. Request-local memoization avoids repeated loads during response construction.

## Explicit experimental-beta limitations

1. Rating coefficients are **experimental and uncalibrated**. Rating is `1000 + clamp[-800,1200](round(4000 * sum(clamp[-10,10](netBB)) / (hands + 10000)))`. Sparse samples remain small; long-run target depends on mean results, not a t-statistic. Raw, unclipped BB and uncertainty remain separate Stats. There is no EV/GTO claim or automatic volume bonus. Leaderboard requires 100 hands; provisional state remains visible.
2. Authored nit/station/lag/maniac policies apply to supported **preflop** nodes only. Postflop currently reuses the saved **balanced** AI policy/defence. DTOs expose `tendencyScope=preflop` and `postflopType=balanced`; types must not be presented as calibrated all-street opponents. Heads-up-only/no-data table rules remain explicit. Missing policies check down, never borrow another spot's policy.
3. Baseline/opponent-adjusted EV deviations remain `null` and `appliedPenalty=0`. Immutable public decision information sets, type, source versions, chosen actions, and available preflop baseline frequencies are retained in shadow observations for offline calibration; frequencies are **not** EV-loss measurements. Missing/unsupported/calibration-unavailable decisions have no penalty.
4. Production migration/readiness and live signed-in play must be verified during delivery. Per-type expected result baselines, robust clipping bias, and ranking/tier thresholds remain uncalibrated beta limitations, not proven skill/EV accuracy. The Free-compatible SQLite DO execution route below removes the standalone Worker 10 ms compute constraint without changing the engine. Offline passing tests and bundling are not deployment or live browser proof.
5. Dataset snapshots and action receipts have no automatic retention cleanup yet. Retention must preserve active/paused replay and retry idempotency and should be reviewed before production use.

## Workers Free execution: SQLite-backed Durable Object

`src/worker.ts` exports the existing HTTP Worker plus `FastFoldRuntime`. Wrangler config declares a `FASTFOLD_RUNTIME` binding and an additive `fastfold-sqlite-v1` migration with `new_sqlite_classes`, not a paid-only legacy KV class. The edge dispatch path does only feature/configuration gates, origin/content-length/cookie-shape checks, a 64-byte digest, finite shard selection and one binding RPC. It performs no D1 queries, JSON payload parsing, replay, defence or account lookup. Missing binding has **no** heavy direct fallback. The DO performs the existing complete account-cookie/expiry, CSRF, legal-action, idempotency and CAS checks on every request. Original cookies, Origin, body stream, response headers and credential CORS are preserved. Shard selection never grants identity.

There are at most **32 session scheduling shards plus one public-status object**, preventing arbitrarily shaped forged cookies from allocating unlimited objects. One account's two valid login tokens can select different shards; D1 CAS/triggers remain authoritative across them. No per-user/private global cache, solver shortcut, substitute opponent policy, action cap, alarm, polling loop or background precompute is introduced. Runtime eviction/restart does not abandon a hand; immutable D1 versions and pause/resume survive.

Cloudflare currently documents SQLite Durable Objects on Workers Free with **30 seconds default CPU per invocation** ([DO limits](https://developers.cloudflare.com/durable-objects/platform/limits/)), separately from the ordinary entry Worker's 10 ms budget. Free includes **100,000 DO requests/day and 13,000 GB-s/day**; exceeding limits fails operations rather than authorizing overage charges ([DO pricing](https://developers.cloudflare.com/durable-objects/platform/pricing/)). The entry Worker request/subrequest limits and D1 read/write/storage quotas still apply. No per-session hand cap is imposed, but the entire service is **not globally unlimited**. No paid upgrade or billing modification is required or performed.

Targeted local verification command: `WORKERD_MODULE=/absolute/path/to/existing/miniflare/dist/src/index.js node --experimental-strip-types --test apps/backend/tests/fastfold-do.test.mjs`. Without that explicit already-installed runtime path the real-DO test skips and must not be claimed successful. Thin-dispatch tests remain credential-free Node tests. Actual local workerd tests use disposable SQLite DO + D1 namespaces and ephemeral authenticated fixture sessions, and cover forged/expired cookies, cross-account rejection, simultaneous same-account retries across different shards, pause/restart/resume and the unchanged saved-policy aggressive flop/river path. Local Node thin-dispatch elapsed timings include asynchronous crypto scheduling and are **not** measured production Worker CPU. Workerd route elapsed timings include D1/RPC I/O and are likewise not `cpu_ms`.

CI uses the same locked official runtime as deployment: `npx --yes --package=wrangler@4.147.0 --call 'node scripts/verify-fastfold-local-runtime.mjs --wrangler "$(command -v wrangler)"'` from `apps/backend`. The helper checks Wrangler's exact package/version, resolves its bundled Miniflare, sets `WORKERD_MODULE`, and runs the authoritative/release/DO tests together. Thus CI cannot silently skip the actual DO binding case for a missing runtime. Locally pass an existing Wrangler path directly to the helper; it never installs anything itself.
