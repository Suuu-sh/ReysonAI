## Contract

`createModel11BehaviorCompletion(inputs, flopArtifact, laterArtifact, options)` first uses the unchanged strict factory to validate source factors, saved envelopes and their hashes/link, balanced-vs-balanced belief and exact pilot configuration. It returns a separately versioned composite execution identity and completion-policy descriptor identity. The fixed balanced belief identity remains unchanged.

- `law`, `rangeState` and `requirementState` remain strict and throw on the original zero-likelihood history.
- `behaviorLaw` and `sample` return the exact original law on path. Only a typed `off-model-observed-action` with a complete certificate can invoke completion.
- `complete(request, ownCombo, certificate)` checks the actor's legal unblocked own cards, positive saved base support and legal public prefix before certificate verification. Every invocation semantically replays the full support/physical law proof and rebinds it to the current public ancestor. Claimed zero, omitted support, stale identity, wrong history, numerical underflow and ordinary unavailable equity do not authorize completion.
- Completion reads only the actor's own hand, revealed board, validated policy and public geometry. The saved-policy lookup retains the original deep-raise fixed rule, `withRaise` and `effectiveMix`. A guarded `Defence` subclass fails if posterior, equity, computed-defence, facts or range-dependent bluff-cap methods are invoked.
- The only extra transformation is the existing public river all-in SPR/tier reroute, when normal bluff-cap mode enables it. Full node action order is retained; continuous final-label remainder is compiled before physical alias pooling. A raw all-in label of zero does not imply its physical class has zero mass.
- Posterior, equity, range floor/ceiling, value/bluff, blockers and inferred MDF adjustment remain explicitly unknown. Pot odds and the geometric MDF target are public chip facts, not a recovered inference.
- There is no global/per-trial off-model switch. Rewinding or starting another trial returns to the strict law normally.
