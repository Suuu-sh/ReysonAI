## old45 workload

1–9). The unchanged original envelopes are read from the selected side. Every
saved report stays original DEF5; each real `defenceFor` factory must report DEF6.
All45 original report identities, policy metadata and complete report contents
are bound to their pinned fixtures. This preserves the legacy factory; it does
not test a model11 consumer adapter.

The fixed boards are Jc9d4h, Jc9d4h2s and Jc9d4h2s8c. The seven exact controls are
flop root; flop bet33 facing; flop bet33/raise facing; turn root after flop33/call;
turn bet33 facing; river root after that flop call and turn check/check; and river
bet33 facing. A genuinely legal root/facing pair is mandatory for every spot.

Each legal control emits full both-seat2704-slot reach vectors, acting-seat base
vector, complete table/chip/log/path snapshot, context/requirement state and exact
representative selection. Laws cover the first8 canonical positive-own-reach
combos plus first2 base-supported zero-own-reach combos when present. They retain
raw/numerical/observable mixes, full facing/betting facts, equity statuses,
immutable action order and every mix boundary with immediate representable
neighbors. Endpoints/out-of-domain random probes are labeled separately.

R2 schemas require the complete stable input/artifact/table/law/settlement fields,
canonical169-hand universe, finite numerical types and exact cent-denominated
chip conservation. Public action-tree nodes, path/log history, pending seat/street,
board length and configured action order must agree. Null-facing context is only
accepted when the emitted opposing reach actually has no positive mass. Facing
and betting facts retain their full stable schemas and legal aggressive-action
coverage. Ordinary null equity/fallback remains an explicit state, never a
fabricated numerical value. JSON exponent overflow is rejected; tagged nonfinite
wire values cannot masquerade as ordinary finite vectors, mixes or chip fields.

The five error probes require their actual named exception/subtype/message
contracts. R3 allows a replay-unavailable record only for the real
`DefencePathError` subtype with an explicitly enumerated path/geometry reason.
Any TypeError or arbitrary exception fails immediately. Even matching legitimate
unavailable controls yield `matched-requires-unavailable-review`, exit1, rather
than a completed scoped preservation gate. No alternate path is substituted.

Four fixed seed strings ×8 fixed-board compatible deals are retained per spot.
Every random call/rejection draw, seed-global index, selected hand, decision

independently checks RNG/ordered choices, binds sampled hands to the exact saved

Counts are recomputed from records. Missing/duplicate laws, cases, probes,
trajectories, full vectors, boundaries or footer fail. Unexercised zero-own,

## Boundaries, receipts and cancellation

One sequential emitter process, at most180 seconds and512 MiB V8 heap. Timeout
uses process-group TERM then KILL after3 seconds. No automatic retry, heap increase
or workload escalation. The local nonblocking lock coordinates only preservation
runs; the shared compute lane requires external coordination.

R4 rejects `..` traversal and all symlink components before canonical containment
or writes, enforces exact runs/name/receipt.json layout, protects the lock and
uses exclusive no-follow file creation. Existing run/evidence names are never
reused. A before receipt precedes child execution. Output, stderr and before
receipt are hashed; final receipts capture source/fixtures/harness/actualGit and
resolved Node binary identities before/after. Separate sides must use identical
Node/harness bytes and distinct verified roots.

SIGTERM/SIGINT/SIGHUP handlers record a stop request without interrupting Popen's
child acquisition. A short bounded wait loop reaps the child through the same
TERM/KILL cleanup before finalizing an interrupted receipt; an already pending
stop prevents launch. Process-level timeout/signal behavior has not been exercised
because no child-process experiment or Node execution is authorized for this
static stage. Forced process death can still prevent a final receipt; before/
partial evidence alone never passes. Source drift, signal, timeout, OOM, nonzero
exit, missing output, launch failure and any validation error remain failures.

Heap is not an RSS cap. `RUSAGE_CHILDREN.ru_maxrss` is maximum child RSS, not the
simultaneous process-tree sum. Large parsed datasets, fact caches and output growth
remain unmeasured. `--check-only` verifies static pins plus genuine471 Git identity;
it does not execute Node or establish Node feature compatibility. The final exact
source integration/diff and runtime still need independent review.

The emitter says `emitted-not-compared`. A separate streaming Python audit checks
receipts and all structured fields. Only full verified equality without unavailable
controls yields `scoped-equality`; it is never production/model adoption.
