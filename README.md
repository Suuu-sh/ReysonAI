# Solvea — ポーカー戦略を、実戦で使える形に

Solvea は、ポーカーの判断を**理解し、練習し、振り返る**ための学習アプリです。主な対象は初心者・初中級者。複雑な戦略を最初から丸暗記する代わりに、局面を選び、レンジを見て、ハンドごとの判断理由を確かめるところから始められます。

現在のレンジは、保存済みの**AI推定**です。数学的な均衡解や GTO ソルバーの出力ではありません。ここで表示する頻度、EV、練習スコアは、勝率や収益を保証するものでもありません。サービスサイトでは `Solvea`、アプリや既存の SDK・環境変数などでは `SolveaAI` の名称を使っています。

> **現在地（2026-09-27）:** プリフロップの推定レンジ閲覧と、それに基づく練習・振り返りを利用できます。フロップの AI 推定は、代表ボードに限った**ローカル実験**です。独立したソルバー基盤も実験段階で、公開レンジの GTO 性を裏付けるものではありません。

## なぜ作るのか

ソルバーは理論を深く調べるための強力な道具です。一方、学び始めた人にとっては、巨大なゲームツリー、細かな混合頻度、数多くの設定が「次の似た局面でどう考えるか」につながりにくいことがあります。

Solvea が解きたいのは、計算結果の量ではなく、**戦略を人が扱える知識に変える難しさ**です。まず重要な判断を見せ、必要になったときに頻度や前提へ進み、練習で理解を確かめられるようにします。理論を省略して正解を断言するのではなく、情報の細かさと確からしさを明示して、学習の入口を作ります。

## 誰のためのアプリか

- **初心者:** ポジション、アクション、レンジの関係を、具体的なハンドから学びたい人。
- **初中級者:** チャートの暗記から進んで、混合判断の理由を知り、苦手な局面を練習したい人。

厳密な均衡解の研究、任意のゲーム条件の即時計算、高度なソルバー設定を主目的とする人にとって、現時点の Solvea は専門ソルバーの代わりではありません。両者は優劣ではなく用途が異なります。

## 届けたい価値

1. **迷わず入口に立てる。** 局面と行動履歴から、その場で参照すべきレンジへ進める。
2. **色の意味まで理解できる。** 169 ハンドの表だけで終わらず、選んだハンドのアクション頻度、サイズ、理由、利用可能な計算前提を確認できる。
3. **覚える量を自分で調整できる。** まず主なアクションをつかみ、必要なときに混合頻度や詳細へ進める。
4. **学習を行動につなげる。** 保存済みレンジに基づくドリル、解説、セッション履歴、弱点・練習傾向の振り返りを使える。
5. **分からないことを分からないまま示す。** 未収録の局面や未計算の値を、別の戦略やゼロで埋めない。

### プロダクトの判断原則

- **理解を先に、複雑さは必要な分だけ。** 簡潔な表示は学びやすさのための入口であり、元の保存頻度を書き換えない。
- **推定と検証済みの結果を混同しない。** 構造検証や監査の合格は、最適性・実戦での利益の証明ではない。
- **データの出所と適用範囲を示す。** 局面、スタック、レーキなどの前提から外れる場合は、そのデータを流用しない。
- **存在しない答えを作らない。** 欠損・不正・未収録は明示し、閲覧操作だけで新しい戦略を生成しない。
- **学習者の成長を測る際も誠実に。** 練習スコアやプレー傾向は、出題された推定レンジとの比較であり、実戦の強さ、収益、GTO への近さとは呼ばない。

| セッション・プレー分析・弱点 | このブラウザーに保存した練習履歴を振り返る。傾向やスコアは、出題された推定レンジに対する練習上の指標。 |

レンジ閲覧の基本条件は **6-max キャッシュゲーム、100BB、アンティなし**です。通常のオープンは 2.5BB、SB オープンは 3.5BB で、SB にはリンプ経路もあります。保存済みデータがない設定や分岐には、戦略を表示しません。プリフロップ推定のコール評価には、低額オンラインゲームを想定したレーキと仮定上の EQR を用いる箇所があります。これらは Solver による実測値ではありません。

トレーナーの結果、セッション、プロフィールはブラウザー内に保存されます。アカウント間の同期はありません。フロップの候補・評価レポートもローカル開発用で、公開済みプリフロップレンジへ自動反映されません。詳細な条件と制限は [`apps/preflop-ui/AGENTS.md`](apps/preflop-ui/AGENTS.md)、[`apps/preflop-ui/src/estimated/AGENTS.md`](apps/preflop-ui/src/estimated/AGENTS.md)、[`apps/preflop-ui/docs/postflop-ai-pilot.md`](apps/preflop-ui/docs/postflop-ai-pilot.md) を参照してください。

## データをどう扱うか

画面が読むプリフロップレンジの正本は、`apps/preflop-ui/src/estimated/` 以下の保存済み JSON です。生成時には独自に作成した局面別プロファイル、シードを固定したエクイティ計算、EQR・EV の仮定、整合性監査などを組み合わせます。外部サービスのレンジ表を転載しません。外部の集計値は、オープンレンジの限定的なベンチマークとして参照する場合があります。

この工程で確認できるのは、入力と出力の整合性、合法なアクション、頻度・サイズの条件、モデル内の一部の損得や警告です。**相手の実際のプレーに対する優位性や、均衡への収束は確認できません。** EV や EQR は用いた相手レンジ、レーキ、実現率などの仮定に依存します。計算していないアクションの EV はゼロではなく「未計算」です。

練習の採点は保存済み推定頻度に対するものです。`Solvea AI Score` は選んだアクションがその推定方針とどれほど一致したかの傾向であり、GTO スコア、EV 損失、勝率ではありません。プレー分析のタイプ名も、このアプリで解いた問題から見える**暫定的な練習傾向**であって、実戦プレーの診断ではありません。

独立した Rust Solver は external-sampling CFR/DCFR を実験実装していますが、継続価値は placeholder を含み、厳密な exploitability や多人数・ポストフロップの均衡検証は未完了です。生成物は構造検証後も `validation.status=provisional`、`gtoVerified=false` として扱います。Solver の研究計画は [`docs/postflop-solver-plan.md`](docs/postflop-solver-plan.md) にあります。

## 今は提供しないこと・将来の方向

自然言語による卓別レンジ調整、対話的な追加質問、高度な学習機能、アカウント、課金は現行アプリでは利用できません。サービスサイトにある Plus の価格・機能は仮案です。これらを実装済み機能として紹介しないでください。

次に進めたいのは、収録局面を増やすことだけではありません。推定の弱点を監査し、フロップ以降の評価を改善し、将来的には自前で品質を測れる Solver の結果と学習体験を接続することです。ロードマップは約束された提供時期ではなく、**理解しやすさと検証可能性を両立するための方向**として扱います。

## 構成

```text
保存済みAI推定レンジ ──► Webアプリのレンジ分析 ──► トレーナー・振り返り
                              │
ローカルのフロップ候補 ────────┘  （試作・読み取り専用）

Rust Solver ──► 構造検証 ──► Solution保存 ──► API / SDK
                                    └──► 検証済み成果物だけをR2へ配布する設計
```

**現在のレンジ分析画面は保存済み JSON を読み、閲覧時に Rust API や Solver を実行しません。** Solver/API 系列は別の実験・配信基盤です。本番向け Edge API は保存済み成果物の読み取り専用で、ローカルの Solver、Worker、Redis へ接続しません。

## ローカルで試す

Node.js を用意し、Web アプリを起動します。**保存済みプリフロップレンジの閲覧とトレーナーに、Rust API や Solver は不要です。**

```bash
cd apps/preflop-ui
npm ci
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

`http://127.0.0.1:4173/` がサービスサイトです。ヘッダーで英語・日本語を切り替えられ、`/app` がアプリです。フロップ試作はローカル候補ファイルが存在し、入力ハッシュなどの条件を満たす場合だけ表示されます。生成・監査の手順は [`postflop-ai-pilot.md`](apps/preflop-ui/docs/postflop-ai-pilot.md) を参照してください。

主な確認コマンド:

```bash
cd apps/preflop-ui
npm run build
npm test
npm run test:sites
```

Rust 側を確認する場合:

```bash
cargo check --workspace
cargo test --workspace
```

API/SDK、Job Queue、R2 公開は開発・配信基盤の作業です。アプリを試すための必須手順ではありません。Edge API の責務は [`apps/solveaai-edge-api/README.md`](apps/solveaai-edge-api/README.md)、ローカルのフロップ試作は上記の専用資料に分けています。
