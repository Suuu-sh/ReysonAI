# 旧 model10 HU レンジのローカルプレビュー

旧 model10 / PR #41 の保存済みHTMLを、そのままローカルで閲覧するための開発用ツールです。保存物は同じディレクトリの [`preview.html`](preview.html) にバイト単位で維持します。保存ソースは `471f8920fd4ed258ca163dd1daa707b75daf1250`。現在の model11 BTN pilot とは別の成果物です。

対象は保存版の1ケース（1 / 407）で、プリフロップ経路は次のとおりです。

```text
UTG 2.5bb オープン → HJ コール → BB 13bb スクイーズ
→ UTG フォールド → HJ コール
```

フロップ開始時は HJ = IP、BB = OOP、ポット29bb、残り有効スタック87bbです。AI推定の保存値であり、GTO解を保証するものではありません。

保存識別子は `UTG_open_HJ_call_BB_squeeze_UTG_fold_HJ_call` です。現在クラウドで検証中の `BTN_open_SB_3bet_BB_call_BTN_fold` / model11 の最終受入とは分けて確認してください。

## 起動と停止

リポジトリのルートから実行します。Node.js標準モジュールだけを使い、依存パッケージのインストールは不要です。

```sh
node tools/hu-model10-preview/serve.mjs
```

ブラウザーで <http://127.0.0.1:5173/dev/hu-model10/> を開きます。サーバーは `127.0.0.1` に限定して待ち受けます。停止は起動したターミナルで `Ctrl+C` を押してください。

ポートを変える場合は `PORT` に1〜65535の整数を指定します。

```sh
PORT=5174 node tools/hu-model10-preview/serve.mjs
```

この例では <http://127.0.0.1:5174/dev/hu-model10/> を開きます。コマンドライン引数は受け付けません。HTTPは `GET` / `HEAD` 専用で、それ以外のメソッドには405を返します。`/` は `/dev/hu-model10/` へ302リダイレクトし、専用パスと厳密に一致しないURL（クエリー付きも含む）は404を返します。

## 操作と表示の読み方

1. 「ボード」で代表12フロップから選びます。
2. 「誰の、どの判断を見る？」で8つの判断から選びます。
3. 13×13の169ハンド表でマスを選ぶと、右側にハンドのアクション内訳とスート別コンボ頻度が表示されます。

判断の選択肢は、BBの最初の判断、BBチェック後のHJ、BBの33%・75%・125%ベットに対するHJ、BBチェック後のHJの各サイズのベットに対するBBです。選択した判断のポットと両者の残りスタックはボードの下に表示されます。内部の `btn_first` というキーも、このケースではHJの判断を表します。

各マスの色幅はアクション頻度です。マス内の数値は、チェックできる判断では合計ベット率、ベットに対する判断では継続率（コール＋レイズ）です。灰色のマスと「—」はレンジ外または到達重みゼロを示し、頻度は表示されません。

対角線はペア、右上はスーテッド（`s`）、左下はオフスート（`o`）です。ハンド詳細にはプリフロップ経路の保存頻度、ボードと重複するカードを除いたコンボ数、各アクションの頻度と金額が表示されます。ハンド単位の頻度は、重複しないコンボを保存レンジ重みで平均した値です。

## 既存アプリとの違いと範囲

既存の `/app` はポジションや行動履歴を選び、対応経路で任意の有効なフロップ・ターン・リバーを扱う試作UIです。このプレビューは経路を固定し、代表12ボード×8判断の保存済み表示を13×13表とコンボ詳細で確認します。新しい戦略の生成や再シミュレーションは行わず、Facingノードも当時の計算済み防御頻度を表示します。

表示対象はフロップのみです。保存HTMLには、1,755フロップの検査を通過し、独立レビューを受けた旨が記載されています。ターン・リバーのランアウトはサンプル検証で、全網羅ではありません。警告を含む限定的な受け入れであり、本番公開や既存アプリUI検証の承認を示すものではありません。

このツールは本番の `public`、ビルド設定、アプリのルートに組み込まず、DBを使用しません。保存HTMLと専用ローカルサーバーで完結します。

## 軽量検証

```sh
node --test tools/hu-model10-preview/serve.test.mjs
```

この検証は専用サーバーの確認用です。戦略の品質監査やターン・リバー全網羅の検証を追加で実施するものではありません。

確認時は7件のサーバーテストが成功しました。保存HTMLの12ボード×8判断、各169ハンド、9,968コンボについて、有限の頻度・到達可能ハンドの合計・ボード重複除外も軽量検査を通過しました。

実ブラウザーで初期の `As7d2c` / BB最初の判断を開き、AAの20%チェック・42%小ベット・33%大ベット・5%オーバーベットと3コンボを確認しました。`Js8s5d` への切替、HJの75%ベット対応、AKsのスート別頻度、72oのレンジ外表示、BBの125%ベット対応への切替も成功し、確認中のブラウザーエラー・警告はありませんでした。既存アプリ内の統合動作、現行model11、ターン・リバー全網羅はこの確認に含めません。
